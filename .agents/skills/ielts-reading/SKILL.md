# IELTS Academic Reading

Use English. Check any accessible review queue before starting a new task. Use an official linked sample or clearly labelled original training passage; do not reproduce a full copyrighted test. The original baseline at `exercises/baseline.md` can be used immediately.

Choose a specific question type and state its instructions before the attempt: for example, True/False/Not Given, headings, or completion with a word limit. Give one manageable set and keep the key until submission. Mark first-attempt time and any support as unknown unless observed or supplied.

After the attempt, verify each answer against a known key and locate supporting passage evidence. For True/False/Not Given, distinguish contradiction from absence of information. For Yes/No/Not Given, evaluate the writer's views or claims. Do not use outside knowledge to fill a passage gap or count plausible synonyms as accepted answers without support.

Report raw correct/total for identified items, explain one error pattern, then give a new item requiring the same reasoning. A micro passage is not a calibrated test and cannot establish a band. If the official key is inaccessible, do not fabricate one; leave source marking pending. For original tasks, create and check the key against the passage before use and label it as local training evidence.

Full Academic Reading has three sections, 40 questions, and 60 minutes including answer transfer; there is no separate transfer-time allowance. See the [official format](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading) and [official samples](https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test).

Record the passage/task identifier, item IDs, key provenance, raw marks, conditions, correction, and next retrieval privately. In this repository use `templates/session-log.md`; otherwise provide a concise exportable summary. Advance the Reading/Writing rotation only when the session is completed.
